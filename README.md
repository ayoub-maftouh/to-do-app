# To-Do App

A simple browser-based to-do list app built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Progress bar that updates with completed tasks
- Empty-state image when there are no tasks
- Saves tasks in `localStorage` so they stay after refresh
- Confetti effect when all tasks are completed

## How to Run

1. Open `index.html` in your browser.
2. Add a task using the input field and plus button.
3. Click the checkbox to mark a task as completed.
4. Use the edit and delete buttons to manage tasks.

## Project Structure

- `index.html` - App layout and markup
- `style.css` - Styling for the app
- `script.js` - App logic, task handling, progress updates, and storage

## Notes

- Tasks are stored in the browser using `localStorage`.
- If you want to reset everything, clear the browser storage for this site.
